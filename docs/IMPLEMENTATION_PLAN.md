# Статус реализации v0.3

Обновлено 14 ноября 2026 года. После обследования фокус изменён на законченный аналитический пример: детерминированное ядро + независимый AI-слой.

## Выполнено

После ревью ядро обновлено до technical-v2: отклонение невалидного времени, контроль торговой активности, свежие bid/ask, разделение качества данных/рыночного стресса/риска позиции, стресс по просадке и направленному движению, независимые эталоны индикаторов. Точная методика — в ARCHITECTURE.md.

- Чистое ядро app/domain без HTTP, БД, системного времени и AI.
- Нормализованные часовые OHLCV Binance, OKX и Kraken.
- Отбраковка невалидной/устаревшей истории, кворум и сравнение общих интервалов.
- SMA, RSI, ATR, волатильность, объём, divergence, версия правил и fingerprint.
- BUY/SELL/HOLD с объяснимыми причинами; сценарий и ограниченный размер BUY.
- AI-комментарий отдельным полем; выключен без запроса.
- Лимит OpenAI до 200000 combined tokens/UTC day с постоянными резервами.
- CLI demo/live, HTTP OpenAPI, Telegram команды без платёжного middleware.
- Отключение незавершённых SaaS-роутеров от основного приложения.
- Автономные unit/contract/integration тесты, конфигурация CI.

## Проверки

Live BTCUSDT: три источника, 120 общих закрытых свечей, без ключей бирж. Реальные AI-запросы в рамках проверки не отправлялись, чтобы не предполагать бесплатность выбранной модели. AI-контракт проверяется подменённым клиентом.

Точные команды: [OPERATIONS](OPERATIONS.md). Результат последнего набора тестов сообщается по фактическому запуску; конфигурация CI ещё не означает публикацию и успешный GitHub Actions run.

## Следующие этапы

1. Подтвердить у владельца бесплатный тариф/модель OpenAI, затем выполнить минимальную проверку AI.
2. Добавить сохранение live-входов и replay для независимой воспроизводимости.
3. Проверить стратегию на исторической выборке и сравнить с базовыми стратегиями.
4. Ввести спред/глубину стакана и обработку рыночных разрывов.
5. Если нужен публичный сервис, отдельно реализовать auth, пользовательские лимиты и эксплуатационную инфраструктуру.

Публикация коммита/репозитория — отдельное действие. Незавершённые платежи и подписки в демонстрацию не включаются.
