# Спецификация v0.3: аналитическое ядро и AI-слой

Дата: 14 ноября 2026 года. Цель версии: воспроизводимая демонстрация инженерных решений работодателю. Базовый [аудит](CURRENT_STATE.md) сохраняется как исторический документ. SaaS-функции предыдущего прототипа не входят в эту версию.

## Контракт

Вход: symbol из BTCUSDT/ETHUSDT/SOLUSDT; mode demo/live; необязательный USDT balance > 0; risk_percent в (0,1]; explain=false по умолчанию.

Выход: core, collection_errors, ai. Core содержит engine_version, input_hash, as_of, mode, согласованную историю, источники, показатели, риск, действие, причины и необязательный trade_plan. AI не является источником чисел.

## Интерфейсы

GET /health — ответ процесса. GET /analysis/demo — demo report. POST /analysis — анализ с валидацией: 422 неверный ввод, 403 HTTP AI выключен, 503 недостаточно качественных данных.

CLI: python -m app analyze --mode demo/live; --symbol; --balance; --risk-percent; --explain. python -m app budget — журнал лимита.

Telegram: python -m app.bot; /start, /demo, /analyze, /signals (alias live).

## Методика

Точные формулы, пороги и структура слоёв: [ARCHITECTURE](ARCHITECTURE.md). Все показатели вычисляются из закрытых 1h OHLCV. Минимум 60 общих последовательных свечей; максимум 120. Старше одного полного часа после ожидаемого закрытия — отказ источника.

Рыночный стресс — инженерная эвристика technical-v2. Его предсказательная сила не проверена исторически. Веса качества данных больше не смешиваются с движением рынка. Стресс — максимум нормализованных ATR, волатильности, абсолютной доходности, просадки и худшего часа. Это не вероятность убытка. Уровни ATR — сценарные, не гарантированные цены исполнения. USDT не переименовывается в USD.

## Критерии готовности демонстрации

- Чистая установка Python 3.13 и pip check.
- Автономные core/provider/AI/API/budget тесты проходят.
- Demo повторяется и явно маркируется.
- Live smoke test получает реальные свечи хотя бы двух бирж.
- OpenAI не вызывается без --explain либо разрешённого HTTP explain.
- Отсутствие ключа или модели не ломает детерминированную часть.
- README и пример walkthrough соответствуют текущему CLI/API.
- CI настроен для Windows/Linux; наличие конфигурации не считается выполненным hosted CI.

## Вне объёма v0.3

Платежи, подписки, хранение портфеля, live-новости, on-chain, полная глубина стакана, multi-timeframe, заявки на бирже, прогноз вероятности доходности и бэктест стратегии. Best bid/ask используется, глубина и размер доступной ликвидности не проверяются. Старый бэктестер не используется ядром и не подтверждает качество его решений.

Следующие инженерные этапы: запись и replay реальных входов, измерение ошибок стратегии на отдельной исторической выборке, калибровка порогов, спред/глубина стакана, наблюдаемость и публичная авторизация. Их наличие не заявляется сейчас.
