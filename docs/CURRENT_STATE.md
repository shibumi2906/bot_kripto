# Текущее состояние

> Исторический baseline до переработки v0.2. Текущее приложение описано в README и TECHNICAL_SPEC.md. Роутеры старого SaaS-прототипа больше не подключены к app.main.

Дата: 14 ноября 2026 года. Объект: локальное рабочее дерево с незакоммиченными исправлениями. GitHub main на момент обследования: e4c3db4f5ec92d8dbab68ffecae8645de8d1747d от 9 июня 2025 года. Локальные изменения в эту версию не входят.

## Архитектура

| Каталог | Назначение |
| --- | --- |
| app/api | FastAPI-роутеры, обращения к БД и сервисам |
| app/bot | aiogram handlers, middleware, создание Bot/Dispatcher |
| app/core | Pydantic Settings, engine/session, модели, схемы, Loguru |
| app/services | Цены, AI, портфель, on-chain заглушка, YooKassa, бэктестер |
| app/tasks | APScheduler, генерация BTCUSDT каждые пять минут |
| app/utils | Валидация, circuit breaker, расчёт доли баланса |
| tests | Три проверки API-ответов и пять случаев валидатора |
| alembic | Пустой каталог, рабочих миграций нет |

app.main создаёт отсутствующие таблицы через create_all в lifespan. Существующая схема таким способом не обновляется. Telegram и scheduler автоматически не запускаются. Redis объявлен в настройках, но в сценариях не используется.

## Фактический API

| Метод и путь | Вход | Поведение |
| --- | --- | --- |
| GET /health | Нет | 200, status=ok; зависимости не проверяет |
| POST /users/register | JSON username | User и неактивная Subscription; повтор имени 400 |
| GET /users/{user_id}/subscription | UUID | Поля записи; 404 при отсутствии; срок не вычисляет |
| GET /signals/ | Нет | Всегда [] |
| GET /portfolio/ | Необязательный user_id UUID | Без ID пустой результат; с ID оценка позиций БД |
| GET /analytics/onchain | network=ethereum, необязательный address | Искусственные 0/0 или 1/0 |
| POST /payments/create-checkout-session | JSON user_id, plan | Stripe Checkout; 503 без конфигурации; только sessionId в ответе |
| POST /payments/webhook | Тело и подпись Stripe | checkout.session.completed активирует подписку на 30 дней |

Аутентификации и проверки владельца в API нет. UUID в запросе не подтверждает право на доступ.

## Данные

User: UUID, уникальный username, created_at. Subscription: UUID, уникальный user_id, is_active, expires_at. PortfolioItem: UUID, user_id, symbol, amount Float. Временные поля без часового пояса.

Telegram ID, платежи, обработанные webhook и история сигналов не сохраняются.

## Реестр проблем

| ID | Наблюдение | Последствие |
| --- | --- | --- |
| A01 | Telegram ID передаётся вместо UUID User | Проверка доступа ошибается, webhook пропускает активацию |
| A02 | Middleware пропускает при отсутствии подписки и ошибке БД, игнорирует expires_at и @bot | Обход ограничений |
| A03 | Роутер bot.payments не подключён | /subscribe недоступна |
| A04 | Checkout URL конструируется из ID | Ссылка не получена из ответа провайдера |
| A05 | Нет журнала событий и обработки продления/отмены | Повторная доставка и состояние подписки не согласованы |
| A06 | Ошибка цены становится нулём | Недостоверная стоимость портфеля |
| A07 | AI fallback содержит искусственные уровни и confidence=0.6 | Ошибка выглядит как аналитический результат |
| A08 | On-chain заглушка выглядит как реальные метрики | Недостоверные данные |
| A09 | SELL использует BUY-условия; HOLD считается сделкой; вход ищется с начала истории | Неверный бэктест |
| A10 | Нет проверки порядка target/entry/stop | Противоречивые сигналы проходят валидацию |
| A11 | Команда портфеля использует пустой список | Реальные позиции не показаны |
| A12 | Пять быстрых ticker-запросов считаются lookback | Исторического анализа нет |
| A13 | Нет аутентификации и проверки владельца API | Доступ к чужим данным по ID |
| A14 | Конкурентный конфликт username не обработан | Возможен 500 при регистрации |

## Проверки и ограничения выводов

В опубликованной версии воспроизведены PydanticImportError конфигурации и SyntaxError portfolio_service. Локальный бэктестер на ценах 100, 105 для SELL (entry=100, target=95, stop=105) и HOLD возвращал profit=5, trades=2, win_rate=1.

Последний pytest 14 ноября завис без вывода и был остановлен. Причина не установлена. Старые тесты не покрывают регистрацию, БД, подписки, webhook и бэктестер. TestClient создаётся без контекстного менеджера, lifespan в этих тестах не проверяется.

Внешние провайдеры реальными запросами в рамках подготовки документации не проверялись.
